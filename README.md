# 🎵 Music Playlist

This is a simple Music Playlist Web Application developed using HTML, CSS, and JavaScript. I built this project to improve my frontend web development skills and to understand how JavaScript can be used to control audio playback and interact with web page elements.

The application allows users to play songs, pause them, and switch between different tracks through an easy-to-use interface. It also displays album covers and song information, making the music player more interactive and visually appealing.

## Features

* Play and pause songs
* Move to the next or previous track
* Display song covers and titles
* Interactive and user-friendly interface
* Responsive design for different screen sizes

## Technologies Used

* HTML
* CSS
* JavaScript

## What I Learned

While building this project, I gained hands-on experience with:

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Enjoy listening to the playlist.
